Hubungkan Repositori GitHub

Menggunakan Personal Access Token (PAT)

📖 Cara membuat Personal Access Token (PAT)
  1. Buka github.com/settings/tokens/new
  2. Beri nama token, contoh: TMPT Code
  3. Pilih expiration sesuai kebutuhan
  4. Centang scope: repo (full control of private repositories)
  5. Klik Generate token → salin tokennya

ℹ️ Token disimpan hanya di localStorage browser Anda. Tidak pernah dikirim ke server TMPT.
