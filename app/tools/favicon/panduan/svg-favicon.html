Menggunakan SVG sebagai Favicon Modern

Dipublikasikan pada TMPT Panduan · 100% Offline-capable

Hampir semua browser modern saat ini telah mendukung file format vektor SVG (Scalable Vector Graphics) sebagai favicon. Dibandingkan file bitmap PNG atau ICO, SVG menawarkan fleksibilitas yang luar biasa.

Kelebihan Menggunakan SVG

  • Ketajaman Sempurna: Karena berbasis vektor matematika, SVG akan selalu tampak tajam di layar apa pun, tanpa peduli seberapa tinggi tingkat kerapatan piksel layar (Retina, 4K, 8K).
  • Ukuran Sangat Kecil: File SVG biasanya berukuran di bawah 2KB, jauh lebih ringan dibanding file bitmap PNG berkualitas tinggi yang berukuran puluhan KB.
  • Mendukung Mode Gelap/Terang (Dynamic Theme): Anda bisa memasukkan kode CSS di dalam file SVG agar warna favicon otomatis menyesuaikan dengan preferensi browser pengguna.

Cara Memasang SVG Favicon

Tambahkan kode berikut ke bagian <head> HTML:

<link rel="icon" type="image/svg+xml" href="/favicon.svg">

Membuat SVG Responsif Tema Gelap/Terang

Di dalam file favicon.svg, gunakan tag <style> yang menyertakan media query untuk mendeteksi preferensi tema pengguna:

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <style>
    /* Warna default untuk mode terang */
    circle { fill: #0f172a; }
    
    /* Warna berubah otomatis di mode gelap */
    @media (prefers-color-scheme: dark) {
      circle { fill: #38bdf8; }
    }
  </style>
  <circle cx="50" cy="50" r="40" />
</svg>

Bagaimana dengan Browser Lama?

Selalu sediakan file favicon.ico cadangan di baris kode paling atas. Browser lama yang tidak mengenali format SVG akan mengabaikannya dan memuat file ICO tersebut.
