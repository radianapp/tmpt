Memasang Favicon di Next.js, React, & Modern Frameworks

Dipublikasikan pada TMPT Panduan · 100% Offline-capable

Framework JavaScript modern sering kali memiliki sistem routing dan build aset mereka sendiri. Berikut adalah cara tercepat memasang favicon di framework terpopuler.

1. Next.js (App Router)

Next.js versi 13 ke atas (App Router) mempermudah manajemen metadata. Anda cukup meletakkan berkas favicon Anda langsung di folder app/ dengan nama berkas khusus berikut:

  • app/favicon.ico (akan disajikan otomatis sebagai /favicon.ico)
  • app/icon.png (untuk favicon umum)
  • app/apple-icon.png (untuk ikon Apple touch)

Next.js akan memproses berkas tersebut dan menghasilkan tag HTML <link> secara otomatis saat proses build.

2. React / Vue / Vite (Single Page Application)

Untuk proyek yang dibangun dengan bundler Vite (seperti template React atau Vue default):

  1. Tempatkan seluruh berkas favicon Anda di folder public/ proyek Anda (misalnya public/favicon.ico, public/favicon-32x32.png).
  2. Akses ikon tersebut di index.html utama di root proyek Anda secara langsung (tanpa perlu menyertakan kata public di path URL):
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">

3. WordPress

Bagi Anda yang menggunakan CMS WordPress:

  1. Masuk ke Dashboard WordPress → Tampilan (Appearance) → Sesuaikan (Customize).
  2. Pilih tab Identitas Situs (Site Identity).
  3. Unggah gambar logo berukuran minimal 512x512 piksel di bagian Ikon Situs (Site Icon).
  4. WordPress akan memproses dan menyajikan tag favicon secara otomatis di seluruh halaman.
