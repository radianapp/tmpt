Cara Memasang Favicon di HTML dengan Benar

Dipublikasikan pada TMPT Panduan · 100% Offline-capable

Memasang favicon di website saat ini tidak sesederhana hanya meletakkan file favicon.ico di root folder. Karena variasi perangkat modern (iOS, Android, Windows, Mac), Anda membutuhkan beberapa baris kode HTML untuk memastikan ikon Anda termuat sempurna di semua layar.

Kode HTML Favicon Standar

Salin blok kode berikut ke bagian <head> file HTML utama website Anda:

<!-- 1. Favicon Utama untuk kompatibilitas klasik -->
<link rel="icon" type="image/x-icon" href="/favicon.ico">

<!-- 2. Ikon Resolusi Multi untuk browser modern -->
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="48x48" href="/favicon-48x48.png">

<!-- 3. Apple Touch Icon untuk iOS (Safari bookmark/home screen) -->
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">

<!-- 4. Manifest Web App untuk integrasi PWA Android/Chrome -->
<link rel="manifest" href="/site.webmanifest">

Contoh Isi File site.webmanifest

Selain tag HTML, PWA membutuhkan berkas JSON bernama site.webmanifest untuk menetapkan informasi detail mengenai aplikasi mobile web Anda:

{
  "name": "Nama Lengkap Aplikasi Anda",
  "short_name": "Singkat",
  "icons": [
    {
      "src": "/android-chrome-192x192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/android-chrome-512x512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ],
  "theme_color": "#ffffff",
  "background_color": "#ffffff",
  "display": "standalone"
}

Tips Tambahan

  1. Root Direktori: Tempatkan seluruh berkas favicon di root folder website Anda (misal https://namadomain.com/favicon.ico). Beberapa bot pencari dan peranti lama hanya akan mencari file favicon di root folder secara otomatis tanpa membaca tag HTML.
  2. Gunakan Absolute Path: Menggunakan tanda garis miring (/favicon.ico) memastikan ikon dapat dimuat dengan benar dari halaman subdirektori manapun.
  3. Gunakan Cache Busting: Jika Anda memperbarui favicon dan perubahan tidak langsung terlihat di browser, tambahkan parameter query versi di ujung URL (misal: /favicon.ico?v=2).
