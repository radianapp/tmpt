Panduan Favicon untuk PWA (Progressive Web Apps)

Dipublikasikan pada TMPT Panduan · 100% Offline-capable

Aplikasi Web Progresif (PWA) memerlukan definisi ikon khusus agar dapat diinstal di smartphone pengguna layaknya aplikasi native. Konfigurasi ini diatur melalui berkas manifest web app.

Apa itu Webmanifest?

site.webmanifest atau manifest.json adalah file konfigurasi berbasis JSON sederhana yang memberi tahu browser cara menampilkan aplikasi web Anda di perangkat seluler atau desktop pengguna.

Ikon Wajib untuk PWA

Ada dua ukuran ikon minimal yang harus dimasukkan ke dalam manifes:

  1. 192x192 piksel: Digunakan untuk ikon di layar utama (home screen) perangkat mobile.
  2. 512x512 piksel: Digunakan untuk splash screen (layar pemuatan awal) saat aplikasi dibuka.

Ikon Maskable (Opsional tapi Sangat Direkomendasikan)

Android memiliki bentuk ikon home screen yang dinamis (bulat, kotak, squircle). Agar ikon Anda tidak memiliki margin putih yang aneh di Android, Anda harus menyertakan properti maskable. Caranya adalah dengan memisahkan area utama gambar (safe zone) sebesar 80% di tengah gambar ikon.
