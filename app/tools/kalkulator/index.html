ℹ️ Tentang TMPT Kalkulator

TMPT Kalkulator adalah platform perkakas terpadu offline-first yang menyediakan 30 kalkulator serbaguna. Terbagi menjadi 4 kategori utama:

  • Finansial & Umum: Menghitung pinjaman, bunga investasi majemuk, PTKP PPh 21, BMI, dan konversi kurs.
  • Statistika Pro: Penentuan sample size, margin of error, uji hipotesis A/B testing untuk peneliti dan marketer.
  • Developer Tools: Format & minify JSON, generate UUID/Hash, konversi Epoch timestamp, pengujian Regex, dan Cron.
  • AI Era Tools: Estimasi biaya token dan API model LLM (OpenAI, Claude, Gemini) untuk kecerdasan buatan.

Pertanyaan yang Sering Diajukan (FAQ)

Apakah data masukan saya aman di TMPT Kalkulator?

Ya, 100% aman. Tidak ada server backend untuk kalkulator ini. Semua perhitungan, logika, pemformatan JSON, enkripsi sandi, dan analisis token diselesaikan sepenuhnya di komputer atau perangkat Anda menggunakan JavaScript.

Bagaimana cara membagikan hasil perhitungan kepada rekan kerja?

Tiap sub-kalkulator dilengkapi tombol "Salin Tautan". Saat Anda mengekliknya, seluruh data input akan diubah menjadi parameter aman di URL. Rekan kerja yang membuka tautan tersebut akan otomatis melihat data terisi dan hasil kalkulasi berjalan instan.

Bagaimana jika saya tidak memiliki koneksi internet?

Sistem ini dirancang offline-first. Kecuali konverter mata uang asing yang sesekali memerlukan koneksi untuk mengunduh kurs kurs terbaru, 29 kalkulator lainnya dapat berjalan sepenuhnya tanpa koneksi internet sama sekali.
