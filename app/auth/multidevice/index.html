Cloud Sync

Simpan dan pulihkan data TMPT ke Google Drive Anda — mudah, aman, dan terenkripsi.

💡 Bagaimana cara kerja Cloud Sync TMPT?

TMPT menggunakan sistem Local-First & Zero-Knowledge. Semua data Anda diproses 100% secara lokal di browser ini.

  • Sync Save (Simpan ke Awan): Mengompres seluruh database Anda menjadi berkas cadangan, mengenkripsinya dengan Kata Kunci Utama Anda, lalu mengunggahnya ke folder konfigurasi Google Drive.
  • Sync Open (Buka dari Awan): Mengunduh berkas terenkripsi dari Google Drive, kemudian mendekripsinya kembali di peramban ini menggunakan Kata Kunci Utama yang sama.
  • Privasi Mutlak: Server TMPT maupun Google tidak pernah bisa membaca isi berkas Anda karena didekripsi secara lokal di peranti Anda.
