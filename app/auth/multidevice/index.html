Akses TMPT di Semua Perangkat

Pelajari cara kerja penyimpanan TMPT dan pilih mode sinkronisasi yang sesuai untuk Anda.

1

Bagaimana Data TMPT Disimpan?

TMPT dirancang local-first: semua data Anda tersimpan langsung di browser perangkat ini — tanpa server perantara, tanpa akun wajib. Ini menjamin privasi absolut dan kemampuan bekerja offline.

Layer 1 — IndexedDB (Aktif saat edit)

Tempat kerja utama. Setiap perubahan langsung tersimpan di sini tanpa latensi. Hanya tersedia di browser ini.

↓ Snapshot otomatis tiap 30 detik
Layer 2 — OPFS Snapshot (Riwayat Versi)

File .tmpt dibuat secara berkala dan disimpan di folder privat browser. Bisa restore ke versi lama. Masih di perangkat ini.

↓ Cloud Sync (opsional — perlu diaktifkan)
Layer 3 — Google Drive / Cloud (Multi-Device)

Snapshot diunggah ke folder tersembunyi milik Anda di Google Drive. Perangkat lain dapat mengunduh dan melanjutkan pekerjaan.

Catatan penting: Data yang di-upload ke Google Drive masuk ke folder appDataFolder yang tersembunyi — tidak tampil di Google Drive UI biasa Anda. Hanya TMPT yang bisa mengakses folder ini.
2

Mengapa Data Tidak Otomatis Tersedia di Perangkat Lain?

IndexedDB adalah storage yang diisolasi per origin + browser + profil OS. Data di Chrome laptop Anda tidak bisa diakses oleh Safari iPad — bahkan jika Anda login ke Google Account yang sama. Ini desain keamanan browser, bukan bug.

Laptop
✅ Data ada
🚫 Tidak terhubung
HP / Tablet
😢 Kosong
3

Pilih Mode Sinkronisasi

TMPT menggunakan pendekatan Progressive Sync — Anda memilih tier sesuai kebutuhan, tanpa memaksa fitur yang tidak diperlukan.

Tier 0

💻 Lokal Saja

Data hanya di browser ini. Cocok untuk penggunaan satu perangkat.

  • ✅ Tidak perlu akun
  • ✅ Privasi absolut
  • ✅ Kerja offline penuh
  • ❌ Tidak bisa diakses dari perangkat lain
  • ❌ Jika hapus browser = data hilang
● Mode aktif saat ini
Tier 1 — Direkomendasikan

☁️ Google Drive Sync

Snapshot otomatis di-upload ke Google Drive Anda. Tersinkron antar perangkat dengan delay ~30 menit.

  • ✅ Data di Drive milik Anda, bukan TMPT
  • ✅ Berfungsi offline (sync saat online)
  • ✅ Riwayat versi (bisa restore ke versi lama)
  • ✅ Vault/Brankas tidak pernah di-sync
  • ⚠️ Ada delay ~30 menit antar perangkat
  • ⚠️ Perlu setup OAuth Google sekali
Tier 2 — Segera Hadir

⚡ TMPT Account (Real-time)

Real-time sync antar perangkat tanpa delay. Cocok untuk tim dan kebutuhan kolaborasi.

  • ✅ Real-time sync (tanpa delay)
  • ✅ Kolaborasi tim
  • ✅ Self-hosted option tersedia
  • ❌ Memerlukan akun TMPT
  • ❌ Berbayar (free tier terbatas)
4

Setup Google Drive Sync

1
Klik "Hubungkan Google Drive"

Anda akan diarahkan ke halaman login Google. Pilih akun Google yang ingin digunakan.

2
Setujui izin akses

TMPT meminta akses ke drive.appdata — folder tersembunyi khusus TMPT. Anda tidak akan melihat file ini di Google Drive biasa.

3
Sync berjalan otomatis

Setelah terhubung, TMPT akan membuat snapshot data dan menguploadnya setiap 30 menit atau saat ada perubahan signifikan.

4
Di perangkat lain

Buka TMPT → Pengaturan → Sync → Hubungkan Google Drive yang sama → Restore dari Cloud.

Vault/Brankas tidak pernah disinkronkan. Data di Vault (password, token) adalah pengecualian keamanan — tidak akan pernah masuk ke cloud, bahkan jika Vault dienkripsi. Backup Vault harus dilakukan secara manual via Pengaturan.
