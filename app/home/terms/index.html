Syarat & Ketentuan

Terakhir diperbarui: Mei 2026

1. Penerimaan Syarat

Dengan menggunakan aplikasi TMPT ("Layanan"), Anda menyetujui untuk terikat oleh Syarat & Ketentuan ini. Jika Anda tidak setuju, harap hentikan penggunaan layanan ini.

2. Sifat Layanan

TMPT adalah aplikasi client-side yang beroperasi sepenuhnya di dalam browser perangkat Anda. Kami tidak menyediakan penyimpanan data di server milik kami untuk data personal Anda.

3. Tanggung Jawab Pengguna

Anda bertanggung jawab penuh atas:

  • Keamanan Kata Kunci Utama Anda. Jika Anda lupa password, tidak ada mekanisme pemulihan. Data Anda akan hilang permanen.
  • Menjaga salinan backup file .tmpt Anda secara berkala. Kehilangan data akibat penghapusan browser cache adalah tanggung jawab Anda.
  • Menggunakan layanan ini sesuai dengan hukum yang berlaku.

4. Batasan Tanggung Jawab

TMPT disediakan "sebagaimana adanya" (as-is) tanpa jaminan apa pun. Kami tidak bertanggung jawab atas kehilangan data yang terjadi akibat lupa password, kerusakan perangkat, atau penghapusan data browser.

5. Perubahan Syarat

Kami berhak untuk mengubah syarat ini sewaktu-waktu. Perubahan akan diinformasikan melalui pembaruan di halaman ini.
