Pusat Bantuan

Panduan cepat untuk memulai dan menggunakan TMPT secara aman

Memulai Cepat

  1. Buat Tmpt Baru: Kunjungi halaman Buat Baru, tentukan Kata Kunci Utama yang kuat (gunakan fitur Generate Passphrase agar mudah diingat), dan simpan hint-nya.
  2. Tambah Data: Di halaman aplikasi (seperti Brankas atau Catat), Anda dapat mulai menyimpan password, catatan, atau data penting lainnya.
  3. Backup Rutin: Kunjungi Pengaturan dan unduh file backup .tmpt secara rutin. Simpan file ini di tempat yang aman.

Pertanyaan Umum (FAQ)

Bagaimana cara pindah ke perangkat baru?

Di perangkat lama: Pengaturan → Export/Backup untuk mengunduh file .tmpt. Di perangkat baru: buka halaman Buka Tmpt, pilih file backup Anda, lalu buka dengan Kata Kunci Utama Anda.

Apa yang terjadi jika saya lupa Kata Kunci Utama?

Data Anda tidak dapat dipulihkan. Ini adalah konsekuensi dari sistem Zero-Knowledge kami — tidak ada pihak lain yang menyimpan kunci enkripsi Anda. Selalu simpan Kata Kunci Utama di tempat yang aman (misalnya ditulis dan disimpan secara fisik).

Apakah aman digunakan di browser bersama / warnet?

Secara teknis ya, namun tidak disarankan. Jika terpaksa, pastikan Anda selalu klik Kunci Tmpt sebelum meninggalkan komputer, dan gunakan mode Private/Incognito agar tidak meninggalkan jejak di browser.

Apakah data saya hilang jika browser di-clear cache?

Ya. Data Brankas disimpan di Local Storage browser. Membersihkan cache/data situs akan menghapus data Anda. Pastikan Anda sudah memiliki file backup .tmpt sebelum membersihkan browser.

Kenapa saya tidak bisa login setelah restore backup?

Saat merestore file backup, Anda harus menggunakan password yang sama dengan saat file backup itu dibuat. Jika Anda sudah mengganti Kata Kunci Utama setelah backup dibuat, gunakan password lama.
