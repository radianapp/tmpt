Kebijakan Privasi

Terakhir diperbarui: Mei 2026

Komitmen Kami

TMPT dirancang sejak awal untuk tidak mengumpulkan data pribadi Anda. Kebijakan privasi ini menjelaskan bahwa: kami tidak memiliki data Anda untuk dilindungi, karena kami tidak pernah menerimanya.

Data yang Tidak Kami Kumpulkan

  • ❌ Nama, email, atau informasi identitas lainnya.
  • ❌ Password atau kunci enkripsi Anda.
  • ❌ Data yang Anda simpan di dalam Brankas.
  • ❌ Riwayat penggunaan, klik, atau perilaku di dalam aplikasi.
  • ❌ Alamat IP atau data lokasi.

Data yang Tersimpan Secara Lokal

Satu-satunya data yang "tersimpan" adalah data Brankas terenkripsi di Local Storage browser perangkat Anda sendiri. Data ini tidak dapat diakses oleh kami maupun pihak ketiga mana pun.

Layanan Pihak Ketiga

Aplikasi ini menggunakan beberapa aset pihak ketiga yang dimuat langsung di browser Anda:

  • PicoCSS — via CDN jsDelivr (hanya file CSS statis, tidak ada pelacakan)
  • HTMX — via CDN unpkg (hanya library JS statis, tidak ada pelacakan)

Pengunduhan aset dari CDN tersebut mungkin merekam alamat IP Anda sesuai kebijakan privasi masing-masing layanan CDN.
