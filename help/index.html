Pusat Bantuan

Panduan cepat untuk memulai dan menggunakan TMPT dengan aman

Memulai

  1. Buat Brankas Baru: Kunjungi halaman Setup, buat Master Password yang kuat (gunakan fitur Generate Passphrase agar mudah diingat), dan simpan hint-nya.
  2. Tambah Data: Di halaman Brankas, klik tombol + untuk menambahkan password, catatan, atau data penting lainnya.
  3. Backup Rutin: Kunjungi Pengaturan dan unduh file backup .tmpt secara rutin. Simpan file ini di tempat yang aman.

Pertanyaan Umum (FAQ)

Bagaimana cara pindah ke perangkat baru?

Di perangkat lama: Pengaturan → Export/Backup untuk mengunduh file .tmpt. Di perangkat baru: buka halaman Login, klik Import (.tmpt), pilih file backup Anda, lalu buka dengan Master Password Anda.

Apa yang terjadi jika saya lupa Master Password?

Data Anda tidak dapat dipulihkan. Ini adalah konsekuensi dari sistem Zero-Knowledge kami — tidak ada pihak lain yang menyimpan kunci enkripsi Anda. Selalu simpan Master Password di tempat yang aman (misalnya ditulis dan disimpan secara fisik).

Apakah aman digunakan di browser bersama / warnet?

Secara teknis ya, namun tidak disarankan. Jika terpaksa, pastikan Anda selalu klik Kunci Brankas sebelum meninggalkan komputer, dan gunakan mode Private/Incognito agar tidak meninggalkan jejak di browser.

Apakah data saya hilang jika browser di-clear cache?

Ya. Data Brankas disimpan di Local Storage browser. Membersihkan cache/data situs akan menghapus Brankas Anda. Pastikan Anda sudah memiliki file backup .tmpt sebelum membersihkan browser.

Kenapa saya tidak bisa login setelah restore backup?

Saat merestore file backup, Anda harus menggunakan password yang sama dengan saat file backup itu dibuat. Jika Anda sudah mengganti Master Password setelah backup dibuat, gunakan password lama.
