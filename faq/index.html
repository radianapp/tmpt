Pusat Bantuan & FAQ

Pelajari cara kerja keamanan data di TMPT Brankas

Di mana data saya disimpan?

Data Anda disimpan 100% di dalam memori browser perangkat Anda (menggunakan LocalStorage). Kami tidak memiliki server untuk menyimpan data Anda. Ini memastikan privasi total, namun berarti Anda bertanggung jawab penuh atas keamanan data tersebut.

Bagaimana jika saya lupa Master Password?

Karena kami mengusung prinsip Zero-Knowledge, tidak ada fitur "Lupa Password" atau Reset Password. Jika Anda lupa password, data Anda tidak akan pernah bisa dibuka kembali oleh siapapun. Kami sangat menyarankan Anda mencatat Master Password di tempat fisik yang aman.

Apa itu file cadangan (.tmpt)?

File .tmpt adalah salinan Brankas Anda yang sudah terenkripsi. Meskipun seseorang mendapatkan file tersebut, mereka tidak akan bisa membacanya tanpa Master Password Anda. Selalu lakukan backup secara rutin sebelum membersihkan cache browser.

Password X vs Password Y (Edukasi Pemulihan)

Saat Anda melakukan "Pulihkan Data", Anda mengganti seluruh Brankas lama dengan isi file backup. Maka, Anda harus menggunakan Password yang digunakan saat file backup tersebut dibuat. Password lama Anda otomatis tidak berlaku lagi karena datanya sudah digantikan oleh data dari file backup.

Bolehkah saya mengubah isi file .tmpt secara manual?

Sangat tidak disarankan. TMPT menggunakan enkripsi AES-256-GCM. Jika Anda mengubah satu karakter saja di dalam file tersebut, sistem akan mendeteksi bahwa file telah rusak/dimodifikasi dan akan menolak untuk membukanya demi keamanan Anda.

Apakah TMPT aman dari Hacker?

Data Anda jauh lebih aman karena tidak pernah dikirim ke internet. Namun, keamanan tetap bergantung pada kekuatan Master Password Anda dan kebersihan perangkat Anda dari malware/keylogger.
