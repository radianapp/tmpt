Tentang TMPT

Filosofi keamanan data berbasis Zero-Knowledge dan Local-First

Misi Kami

TMPT dibangun dengan satu tujuan utama: Mengembalikan kendali privasi data sepenuhnya ke tangan Anda. Di era di mana data pribadi sering disalahgunakan, dilacak, atau bocor dari server perusahaan besar, kami percaya bahwa cara teraman menyimpan data adalah dengan tidak memberikannya ke pihak lain sama sekali.

Apa itu Zero-Knowledge?

Konsep Zero-Knowledge berarti kami (pembuat TMPT) memiliki nol pengetahuan tentang apa yang Anda simpan. Kami tidak memiliki server, database pusat, ataupun fitur pelacakan analitik. Data Anda hidup dan mati di perangkat Anda sendiri.

  • Tidak ada proses registrasi email.
  • Tidak ada sinkronisasi cloud pihak ketiga secara diam-diam.
  • Segala proses enkripsi (AES-256-GCM) terjadi secara lokal menggunakan chip dan browser perangkat Anda sendiri.
